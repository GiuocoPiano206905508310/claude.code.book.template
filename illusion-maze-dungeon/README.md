# 錯視迷宮の勇者(だまし絵ダンジョン)

Three.jsで動く、ブラウザ版の見下ろし視点アクションパズルゲーム。デザイン画帳(勇者・建物・モンスター・仕掛け・アイテム・全体マップ)は確定済みです。このフォルダには、実装順序の**ステップ4「小宝箱と回復薬・盾」**までを、実際に動く形で入れています。

外部ライブラリはCDNに頼らずこのフォルダに同梱しているので(`vendor/three.module.min.js`)、ネット接続がなくてもそのまま動きます。

## 遊び方

このフォルダをブラウザで直接開く(`index.html`をダブルクリック)のではなく、簡易サーバー経由で開いてください。`type="module"`の読み込みはブラウザのセキュリティ制限で`file://`だと動かないためです。

```bash
cd illusion-maze-dungeon
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

(Node.jsがあれば `npx serve` などでも構いません)

## 操作

| キー | 動作 |
|---|---|
| 矢印キー / WASD | 移動(カメラの向きが基準) |
| `[` / `]` | カメラを90度回転 |
| `G` | 重力面を切り替える(床 → 北の壁 → 天井 → 床…)※デバッグ用 |
| `E` | 近くの宝箱を調べる |
| `Q` | 回復薬を使う(HPを30回復) |
| `R` | 盾を使う(次に受けるダメージを1回無効化) |
| `H` / `J` | ダメージ・回復のテスト用ショートカット |

## 今回入っているもの・まだ入っていないもの

- ✅ 4方向・90度ずつ滑らかに切り替わるアイソメトリックカメラ
- ✅ カメラの向きを基準にした移動・旋回
- ✅ 重力面(床／壁／天井)を切り替える仕組み。`G`キーで確認できる、勇者が新しい面に向かって滑らかに「起立」し直すデモです。実際の重力反転床・反転梯子ギミック(踏むと発動する等)はステップ6・7で追加予定
- ✅ 勇者のプレースホルダー(カプセル+マント色+盾色の簡易モデル)。実際の見た目はデザイン画帳の生成イラストをもとに、後工程でモデル/スプライト化します
- ✅ HP・ダメージ・無敵時間・ゲームオーバー画面。赤茶色の罠タイルに触れるとダメージを受ける、共通の`takeDamage()`経由でどの発生源からも呼べる作り
- ✅ 小宝箱(2個)・回復薬・守りの盾。宝箱に近づくと「調べる」表示が出て、開けると対応するアイテムが所持数に加わる。使うと即座に効果が発動(回復薬はHP30回復、盾は次の1発を無効化して金色のリングが出る)
- ⬜ モンスターAI・戦闘(ステップ5)
- ⬜ ステージ1の建物・仕掛けの実体化(ステップ6)。今の床・壁・天井はテスト用の仮床で、Stage 1そのものではありません
- ⬜ スマートフォンのタッチ操作は、リポジトリのこのバージョンにはまだ入っていません(`game.js`の`keys`セットに書き込む入力ソースを増やせば拡張できる構造にはしてあります)。公開中のプロトタイプURL版には画面ボタンでのタッチ操作を先行実装済みです

## ファイル構成

```
illusion-maze-dungeon/
  index.html      画面とUIオーバーレイ
  style.css       最小限のスタイル
  game.js         ゲーム本体(カメラ・移動・重力面の切り替え)
  vendor/
    three.module.min.js   Three.js本体(同梱、CDN不要)
```
