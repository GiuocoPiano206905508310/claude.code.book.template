# 給与・勤怠管理システム

複数の従業員に対応した、ブラウザだけで動く給与計算ソフトと勤怠管理ソフトです。勤怠の集計結果（残業時間・欠勤日数など）が給与計算画面に自動反映される、連動型のシステムになっています。

デモ: https://giuocopiano206905508310.github.io/claude.code.book.template/

## 画面構成

- **ダッシュボード**（`index.html`）: 登録従業員数、当月の給与明細作成状況、各画面へのリンク
- **従業員マスタ管理**（`employees.html`）: 氏名・雇用形態・年齢区分・保険料率・扶養人数・所定労働時間などの登録
- **勤怠管理**（`attendance.html`）: 従業員・対象月ごとの日次打刻（出勤・退勤・休憩・休暇区分）入力と、残業・欠勤・遅刻・早退の月次自動集計
- **給与計算**（`payroll.html`）: 従業員マスタと勤怠集計をもとに残業手当・欠勤控除を自動算出し、社会保険料・源泉所得税を計算。月次の給与明細として保存・履歴管理・印刷/Excel/コピー出力に対応
- **賞与計算**（`bonus.html`）: 賞与額・前月給与から社会保険料・源泉徴収税額を計算し、明細を保存

## データの保存について

従業員データ・勤怠データ・給与明細・賞与明細は、すべてお使いのブラウザの `localStorage` にのみ保存されます。外部のサーバーへ送信されることはありません（別の端末・別のブラウザとはデータは共有されません）。

## 技術構成

ビルド不要の静的サイトです。GitHub Pages でそのまま公開できます。

- `calc.js`：保険料率・源泉徴収税額表・給与/賞与計算ロジック（DOM非依存の純粋関数）
- `data.js`：localStorage を用いたデータ層（従業員・勤怠・給与明細・賞与明細のCRUDと月次集計）
- `common.js`：ナビゲーション・数値フォーマット・印刷/Excel出力などの共通UIヘルパー
- `employees.js` / `attendance.js` / `payroll.js` / `bonus.js` / `dashboard.js`：各画面のロジック

## 注意事項

個人・小規模事業向けの概算ツールです。正式な給与計算・勤怠管理・税務手続きには、給与計算ソフトまたは社会保険労務士・税理士等の専門家にご確認ください。
