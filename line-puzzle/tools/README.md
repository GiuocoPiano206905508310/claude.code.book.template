# ステージ生成・検証ツール

`levels.js` は手書きではなく、ここのスクリプトで生成・検証しています。

## 1. 候補プールを作る（数分かかります）

```sh
python3 generate-pool.py pool.json
```

盤面をランダムに作り、幅優先探索で「全マスを塗り切る最短手順」が存在するものだけを集めます。
盤面サイズごとに時間予算を割り当てており、4,000件程度のプールができます。

## 2. 50ステージを選んで levels.js を書き出す

```sh
python3 build-levels.py pool.json ../levels.js
```

最短手数と盤面サイズがなだらかに上がるよう50件を選び、
書き出す前に全件を再生検証します（手順を再生して全マスが塗られるか、
空振りの手が混ざっていないか、盤面が連結しているか）。

## 3. ブラウザで通しテストする

```sh
# リポジトリのルートで
python3 -m http.server 8777 --bind 127.0.0.1 &
node tools/test.mjs      # 要 playwright
```

ユーザー名バリデーション（重複・NGワード・文字種）、全50ステージの自動クリア、
オートセーブと再開、各ボタンの動作、アイコンが単色かどうかを確認します。
