# ラインパズル（Line Puzzle）

まっすぐにしか進めない芋虫を操作して、盤面のすべてのマスを塗りつぶすパズルゲームです。
ブラウザだけで動作し、**ユーザー登録は不要**です（サーバー不要）。

## 遊び方

- 芋虫は**お邪魔ブロック（灰色）・盤面の端・すでに通ったマス のいずれかに当たるまで直線に滑り続けます**。
  途中で止まることはできません。
- 通ったマスは紫色に塗られ、**二度と通れません**。自分の通った跡が新しい壁になります。
- **すべての通れるマスを塗りつぶすとクリア**です（＝直線移動だけで作る一筆書き）。
- 進む向きを誤ると、塗り残しを回収できなくなって詰むことがあります。
  詰みの自動通知は行わないので、行き詰まったら ↪ でやり直してください
  （💡 を押したときだけ、その局面が詰んでいる旨を知らせます）。
- 操作: **スワイプ**、または 矢印キー・WASD（十字ボタンは廃止し、そのぶん盤面を大きく取っています）

## 画面のボタン（モノクロアイコン）

| アイコン | 名前 | 動作 |
| --- | --- | --- |
| ↪ | やり直す | 現在のステージを最初から やり直します（画面**左下**） |
| ⏸ | 中断 | ゲームを一時停止し、再開・やり直し・ステージ選択・ユーザー切替を選べます（画面右上） |
| 💡 | ヒント | 次に進むべき方向を矢印で表示します（画面**左下**。使用回数は記録され、★は最大2つになります） |

すべてのアイコンは `currentColor` 1色で描かれた単色SVGです（絵文字は使用していません）。

## ステージ

- 全 **50 ステージ**。
- `levels.js` のデータはスクリプトで自動生成し、**深さ優先探索で解が存在することを全件検証済み**です。
  各ステージの `sol` が最少手数の解（`U` `D` `L` `R`）で、ヒント機能と★判定に使われます。
- 生成は**正解の経路を先に引き、止めたい位置にお邪魔ブロックを置いていく逆算方式**です。
  ランダムにブロックを置く方式だと、解ける盤面がほぼブロック0〜1個のものに偏ってしまい、
  スカスカの盤面しか作れませんでした。逆算なら経路が保証されるため、ブロックを好きなだけ置けます
  （現在は1ステージあたり平均30個、最大59個）。
- 難易度は次の指標を合成したスコアの順に並べてあります。
  - 塗るマスの数（盤面の大きさ）と **お邪魔ブロックの数**
  - 正解手順上で2方向以上選べた回数＝**迷いどころの多さ**
  - 全解探索で辿ったノード数＝**後戻りの多さ**
  - 解の総数（少ないほど難しい。多くのステージは**解が一意**です）
- 一本道（分岐が無く考える余地がない）盤面と、ブロックが少なすぎる盤面は候補から除いています。
  さらに終盤（Level 31以降）は、**迷いどころが3つ以上ある盤面だけ**を使います。
- 難易度の目安

  | | 盤面 | 塗るマス | ブロック | 最少手数 |
  | --- | --- | --- | --- | --- |
  | Level 1 | 5x4 | 16 | 4 | 9手 |
  | Level 25 | 10x9 | 54 | 36 | 14手 |
  | Level 50 | 12x11 | 73 | **59** | 20手（解が一意） |

## セーブデータ

- **ユーザー登録もログインも不要です。** 開いたらそのまま遊べます。
- ステージを**クリアした時点で自動保存**されます（`localStorage` のキー `linePuzzle.progress.v1`）。
- **同じブラウザで開けば続きから遊べます。** 時間をあけて開き直すとステージ選択画面が出て、
  ▶ ボタンで**未クリアの最初のステージ**にすぐ入れます。
- 保存内容: クリア済みステージ・★の数・最少手数。
- 保存先はブラウザの中なので、別の端末や別のブラウザには引き継がれません。
- `localStorage` が使えない環境では、セッション中のみメモリ上に保持し、その旨を画面に通知します。

## クリア後の選択肢

| ボタン | 動作 |
| --- | --- |
| 次のステージへ | 次のステージに進みます |
| 再チャレンジ | 同じステージをもう一度、最初から遊びます（★を取り直せます） |
| ステージ選択へ | ステージ一覧に戻ります |

★は**黄色の塗りつぶし**で表示します。未獲得のぶんは同じ黄色を薄くして、いくつ取れたかが
一目で分かるようにしています。★の付け方は、最少手数でクリアすると3つ、+2手までなら2つ、
それ以上なら1つ。ヒントを使った場合は最大2つになります。

## 起動方法

`line-puzzle/index.html` をブラウザで開くだけです。

`localStorage` をブロックするブラウザ設定（`file://` を制限する場合など）では、
ローカルサーバー経由で開いてください。

```sh
cd line-puzzle
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## 盤面の見た目

未通過のマスは**葉っぱ**として描いています（芋虫が葉を食べ進むイメージ）。
葉はインラインSVGをデータURIにしてマスの背景に敷いており、向きの違う4枚を
マスの位置 `(x + y*2) % 4` で振り分けて、同じ模様が並ばないようにしています。
葉脈は低コントラストにして、緑（未通過）・灰色（ブロック）・紫（通過済み）の
区別が鈍らないようにしています。

## 配色

| 要素 | 色 |
| --- | --- |
| 周りの背景 | 灰色 |
| 盤面の未通過マス | 緑色の**葉っぱ**（食べられていない葉） |
| お邪魔ブロック | 灰色 |
| 通過済みのマス（芋虫が食べた跡） | 紫色 |
| 芋虫の顔・触角 | 紫色（白い顔に触角2本） |

## 更新するとき

`index.html` は `style.css?v=...` のように**中身のハッシュを版数**として付けています。
CSS や JS を変更したら、公開前に必ず版数を付け直してください。付けないと利用者の
ブラウザが古いファイルをキャッシュから読み続け、変更が反映されません。

```sh
python3 tools/stamp-assets.py
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面構造とモノクロSVGアイコン定義 |
| `style.css` | レイアウトとアニメーション |
| `game.js` | ゲームロジック・ユーザー管理・セーブ・ヒント用ソルバー |
| `levels.js` | 全50ステージのデータ（自動生成・検証済み） |
| `tools/stamp-assets.py` | CSS/JS の版数(?v=)を中身のハッシュで付け直す |
