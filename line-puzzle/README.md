# ラインパズル（Line Puzzle）

まっすぐにしか進めないキャラクターを操作して、盤面のすべてのマスを塗りつぶすパズルゲームです。
ブラウザだけで動作します（サーバー不要）。

## 遊び方

- キャラクターは**壁（緑のブロック）や盤面の端に当たるまで直線に滑り続けます**。途中で止まることはできません。
- 通ったマスは黄色く塗られます。塗り済みのマスの上も通過できます。
- **すべての通れるマスを塗りつぶすとクリア**です。
- 操作: スワイプ / 矢印キー・WASD / 画面下の十字ボタン

## 画面のボタン（モノクロアイコン）

| アイコン | 名前 | 動作 |
| --- | --- | --- |
| ↪ | やり直す | 現在のステージを最初から やり直します |
| ⏸ | 中断 | ゲームを一時停止し、再開・やり直し・ステージ選択・ユーザー切替を選べます |
| 💡 | ヒント | 次に進むべき方向を矢印で表示します（使用回数は記録され、★は最大2つになります） |

すべてのアイコンは `currentColor` 1色で描かれた単色SVGです（絵文字は使用していません）。

## ステージ

- 全 **50 ステージ**。
- `levels.js` のデータはスクリプトで自動生成し、**幅優先探索で最短手順が存在することを検証済み**です。
  各ステージの `sol` がその最短手順（`U` `D` `L` `R`）で、ヒント機能と★判定に使われます。
- 難易度は最短手数と盤面サイズが少しずつ上がるように並べてあります。

## ユーザー名の登録

- 2〜12文字。ひらがな・カタカナ・漢字・英数字が使えます。
- **同じユーザー名は登録できません。** 全角/半角・大文字小文字・ひらがな/カタカナ・空白や記号での回避を
  正規化したうえで重複を判定します（例: `ぱずる太郎` と `ﾊﾟｽﾞﾙ太郎` は同一とみなします）。
- **卑猥な言葉・差別的な言葉・なりすまし目的の名前は使用できません**（`game.js` の `NG_WORDS`）。

## セーブデータ

- ステージを**クリアした時点で自動保存**されます（`localStorage` のキー `linePuzzle.save.v1`）。
- 時間をあけて開き直すと最後に選んでいたユーザーのステージ選択画面から再開でき、
  ▶ ボタン（つづきから）で**未クリアの最初のステージ**にすぐ入れます。
- 保存内容: ユーザー名・クリア済みステージ・★の数・最少手数。
- `localStorage` が使えない環境では、セッション中のみメモリ上に保持し、その旨を画面に通知します。

## 起動方法

`line-puzzle/index.html` をブラウザで開くだけです。

`localStorage` をブロックするブラウザ設定（`file://` を制限する場合など）では、
ローカルサーバー経由で開いてください。

```sh
cd line-puzzle
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面構造とモノクロSVGアイコン定義 |
| `style.css` | レイアウトとアニメーション |
| `game.js` | ゲームロジック・ユーザー管理・セーブ・ヒント用ソルバー |
| `levels.js` | 全50ステージのデータ（自動生成・検証済み） |
